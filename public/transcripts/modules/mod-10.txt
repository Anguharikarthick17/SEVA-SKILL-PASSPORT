### Part 2: Code Example: Interactive Rebase & Branch Sync
*Linear Commit History Hygiene*

> "Interactive rebasing allows developers to clean up work-in-progress commits into atomic units with clear messages, producing an auditable project history."

```javascript
# Sync feature branch with main linearly
git checkout feature/passport-telemetry
git fetch origin
git rebase origin/main
# Squash messy WIP commits into clean atomic units
git rebase -i HEAD~3
```
