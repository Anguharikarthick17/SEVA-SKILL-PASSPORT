### Part 2: Code Example: Robust Parallel Async Execution
*Promise.allSettled for Fault-Tolerant Aggregation*

> "Using Promise.allSettled lets you run concurrent asynchronous requests safely. If one network call fails, other data still loads successfully."

```javascript
async function fetchStudentDossier(studentId) {
  const results = await Promise.allSettled([
    fetchProfile(studentId),
    fetchEvidence(studentId),
    fetchAssessments(studentId),
  ]);
  return results.map(r => r.status === 'fulfilled' ? r.value : null);
}
```
