### Part 2: Code Example: Memory-Safe Stream Pipeline
*Processing Large Datasets without Out-of-Memory Errors*

> "Notice how pipeline streams data directly from source to destination with automatic backpressure management, preventing out-of-memory errors on large payloads."

```javascript
import { pipeline } from 'node:stream/promises';
import fs from 'node:fs';
import zlib from 'node:zlib';

await pipeline(
  fs.createReadStream('telemetry-dump.log'),
  zlib.createGzip(),
  fs.createWriteStream('telemetry-dump.log.gz')
);
```
