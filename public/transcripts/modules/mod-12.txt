### Part 2: Code Example: Multi-Stage Dockerfile for Next.js
*Minimal Production Attack Surface*

> "Multi-stage Docker builds isolate the build environment from the production runtime, generating lightweight, secure container images without build tool clutter."

```javascript
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production
COPY --from=builder /app/.next/standalone ./
EXPOSE 3000
CMD ["node", "server.js"]
```

### Part 3: Common Mistake & Anti-Pattern
*Hardcoding Production Secrets in Code or Docker Images*

> "Never commit API keys or database passwords to Git repositories or bake them into Docker images. Always inject secrets at runtime through secure environment variables."
