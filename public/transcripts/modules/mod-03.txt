### Part 2: Code Example: Encapsulated Counter with Closures
*Private State Preservation*

> "In this example, the inner functions maintain a live reference to the private count variable. Outside code cannot mutate count directly, demonstrating encapsulation."

```javascript
function createTelemetryTracker(initialCount = 0) {
  let count = initialCount;
  return {
    increment: () => ++count,
    getCount: () => count,
  };
}
const tracker = createTelemetryTracker(10);
tracker.increment(); // returns 11
```
