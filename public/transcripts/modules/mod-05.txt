### Part 2: Code Example: Custom Hook for Async Data Fetching
*Clean State Encapsulation with AbortController*

> "This custom hook encapsulates asynchronous data loading. It integrates an AbortController in the cleanup function to prevent memory leaks when components unmount."

```javascript
function usePassportEvidence(userId) {
  const [data, setData] = useState(null);
  useEffect(() => {
    const controller = new AbortController();
    api.getEvidence(userId, { signal: controller.signal })
       .then(setData)
       .catch(err => { if (!controller.signal.aborted) console.error(err); });
    return () => controller.abort();
  }, [userId]);
  return data;
}
```

### Part 3: Common Mistake & Anti-Pattern
*Infinite Re-render Loops in useEffect*

> "Never omit dependencies from useEffect to silence warnings. That causes stale closures or infinite re-render loops. Always declare dependencies honestly."
