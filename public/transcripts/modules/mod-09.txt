### Part 2: Code Example: Secure Row Level Security (RLS) Policy
*PostgreSQL Defense-in-Depth Authorization*

> "PostgreSQL Row Level Security ensures that even if application code is misconfigured, the database engine prevents users from querying unauthorized records."

```javascript
CREATE POLICY "Users can only inspect own evidence"
ON public.evidence_timeline
FOR SELECT
TO authenticated
USING (user_id = auth.uid());
-- Denies direct access to arbitrary records
```

### Part 3: Common Mistake & Anti-Pattern
